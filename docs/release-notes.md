RC5 修了「新建连接」带着上一台机器参数的问题、RC6 修了重开之后「最近使用」分组消失的问题、
RC7 修了「主机密钥变了」那句处理提示一直没发到界面上的问题、RC8 修了并发写日志会丢行（崩溃那条也会丢）的问题、
RC9 修了「复制诊断信息」碰到一个坏字节就把整份日志读成空的问题、RC10 修了「定位日志文件」在路径含空格的机器上
（`C:\Users\Tyler Zhang\` 这种）按了没反应的问题、1.0.7-RC2 修了日志刚轮转那一下「看日志」读到空的问题，
这些版本各有自己的包。1.0.8-RC1 修的是回归里两处「检查产物」的判据（安装包只认当前版本那只、可执行文件跟着 `CARGO_TARGET_DIR` 走），RC2 让回归脚本能只跑某一项，改一处、核一处不用整跑；RC3 又把推上去才现形的那两道带进回归——`cargo fmt --check` 与 `cargo clippy -D warnings` 成了 A32，本地过了就等于 CI 那关也过了。
上一版 1.0.8-RC4 修的是查找：一条长命令被终端折成两行、要搜的词正好骑在折点上时，以前两行各自都凑不出完整那串，搜不到；现在先按折行把几行拼成一条再扫，命中的位置按格算回来，跳过去整串都被选中（硬换行两侧各一半的情况不算命中，不会凭空多出可疑结果）。
上一版 1.0.8-RC5 修的是版本号本身：以前一次进位只核对清单里的三处，标题栏那个数字与 `Cargo.lock` 里三个 crate 的版本没人管——界面可能自己说着上一版，锁文件也可能停在上一版，谁用 `--locked` 构建就当场红。现在进位一次写全七处、核对一次也是七处，哪一处不一样就点名哪一处。
上一版 1.0.8-RC6 修的是「回归全绿」这句话本身：以前只要没有失败就退出 0，于是那些**没跑**的项（这一版还没打包、截图清单还没出、机器上没有 Chrome、`--fast` 跳过了 `cargo test`）都混在同一句「通过 / 跳过」里看着像全绿。现在没核过的单列成「未验」，汇总写「N 通过 / N 失败 / N 未验」，退出码也分成 0 / 1 / 2 / 3，未验的每一项都写明为什么没跑。
上一版 1.0.8-RC7 补的是另一个「核了外壳、没核里头」：A10 一直只读 PE 头里那个字段，它只能说明这份 exe 被标记成窗口程序，说明不了它跑起来会不会当场退出、窗口画不画得出来。现在 A33 真把它拉起来——等窗口、核标题里带 `Portio`、再盯几秒确认没当场崩，最后连子进程一起收干净，不在你桌面上留窗口。
上一版 1.0.8-RC8 补的是同一件事的下一层：A33 拉起的那份，其实一直是我本机的 debug 构建，而你在 Releases 里下到、我交给你的，是 release 构建打出来的包——体积 4591521 对 3382127，差的那一截就是「我核的」和「你装的」不是同一个东西。现在构建、核验、认包、交付统一到 release：A33 的结论里必须写着核的是哪一档，A11 认安装包也只认跟它同一档的目录，debug 包顶不上去。
上一版 1.0.8-RC9 补的是这两步之间还剩的那一步：**安装包里面到底放了哪份 exe**。以前我只核了包外面的名字与体积，一个名字刚好的旧包、或者打包时拿错了二进制，都会照旧报绿。现在核验会把包装拆开（只拆不装），拿里面那份 `portio-app.exe` 跟构建产物逐字节对。这里有个细节值得说：两份 exe 字节数一样、哈希却不同，差的 3 个字节是打包器自己写进去的包型标记（`UNK` → `NSS`）——所以我精确抹掉这几位再比，别处差一个字节就算不是同一份。
上一版 1.0.8-RC10 补的是同一类问题里「核它的脚本」那一层。我这些天一直在核「以为绿了其实没核」，而核这件事本身，靠的是 `scripts/` 下那批单测（154 条）。它们只在 CI 里被跑——`ci.yml` 里有一步`python -m unittest discover -s scripts`——而我本地整跑时，A1 是 `cargo test`、A32 是 fmt/clippy，这一批从头到尾没进过整跑。于是改完回归脚本却忘了跑对应单测的时候，本地三十几项全绿、推上去 CI 才红，跟「本地的绿要等于 CI 的绿」正好相反。现在 A35 把这一批按 CI 同一条命令纳入整跑；而且「一条都没跑到」也算红——那正是假装跑过的样子。
1.0.9-RC1 再往里一层：**窗口起来了，不等于界面画出来了**。上一版会拉起 `portio-app.exe`、核进程没退、标题带 `Portio`——可那个标题是配置文件里写死的，窗口一开就挂着，界面里一根筋没加载也照样成立。现在这一项走 WebView2 自己的调试口（只对那一个子进程开，机器上任何设置都不动），进真 webview 读 DOM：页面有没有从 `about:blank` 导航到界面、`readyState` 到没到 `complete`、标题栏那个版本串是不是这一版的、`app.js` 里的函数在不在、终端对象建没建、DOM 有没有肉。顺带一个真相：仓库 `target\debug` 里那份 exe 是 1.0.7-RC3 时期构建的，界面里还写着 RC3 的版本号，而上一版那一项一路绿灯。

## 正文（整段可粘贴）

### Portio 是什么

我在服务器上干活时最烦的是来回切窗口：一边 `ssh`，一边另开一个工具拖文件，路径还得手打一遍。
Portio 就是把这两件事塞进一个窗口——左边是主机清单，中间是终端，右边是远端和本机两栏文件。
一个窗口里，命令往下走，文件往上走。

名字取 **port + io**：port 是 SSH 端口，也是数据的进出口。

### 这一版能做什么

**终端**
- 多个标签页，一页一台机器；`Ctrl+T` 新开，`Ctrl+W` 关掉（最后一个不关）。
- **分屏**：`Ctrl+Shift+D` 左右分、`Ctrl+Shift+E` 上下分、`Ctrl+Shift+W` 关当前格，最多四格。
  已连接的主机里分出来的格子会单独再开一条通道，不是两格共用一个 PTY。
- **查找**：`Ctrl+F` 浮出一条查找栏，扫整条缓冲区（含滚出屏幕的旧行），`Enter` 下一个、`Esc` 收起。
- **复制粘贴按老习惯**：`Ctrl+Shift+C` / `Ctrl+Insert` 复制，`Ctrl+V` / `Shift+Insert` 粘贴；
  `Ctrl+C` 有选中就复制、没选中才发中断——不会再一次"想复制结果把命令打断了"。
- 字号可调，`F5` 重绘，窗口缩放时列数行数跟着走。

**文件**
- 远端 / 本机双栏，双击进出目录，拖拽即上传，`F5` 刷新两侧。
- 传输队列带逐块进度，能收成一行；**断点续传**：下载写 `原名.portio-part`，上传写远端
  `名.portio-part`，断了接着传，传完改名。
- 远端文件行带权限列（`-rwxr-xr-x` 这种），中文名、空格、`#`、`&` 的路径都试过。

**会话**
- 会话写在 `%APPDATA%\io.portio.desktop\sessions.json`，双击就连；能分组、能搜、能重命名。
- **快速连接**：会话栏那行写 `user@host:port`，回车直接跳到连接面板，端口与认证方式按上次记录带出来。
- **从别的工具搬过来**：一个「导入会话」下拉，三项——`~/.ssh/config`、Xshell 的会话目录、WinSCP 的站点。
  通配符块、`Match` 块、RDP/Serial、FTP/WebDAV 站点会跳过并计数；三个来源的密码一律不读。

**安全**
- 口令用 AES-256-GCM 加密存在本机（`credentials.json`），勾「记住口令」才存；主密钥首次用到才生成。
- 主机指纹照 SSH 的规矩走：第一次连记下指纹（TOFU），**变了就拦下**，不会"自动接受"。
  设置里有「已知主机」列表，能看指纹、删记录；删了只是下次重新走一遍首次信任，标准没降。

**出问题的时候**
- 本机运行日志（`%LOCALAPPDATA%\io.portio.desktop\logs\portio.log`）记 Rust 崩溃和前端异常，
  满 1 MiB 轮转；设置面板能一键定位文件、一键「复制诊断信息」（版本 + 系统 + 窗口尺寸 + 最近 20 行）。
- 连不上的七类常见原因都有自己的说法（认证被拒 / 拒绝连接 / 超时 / 远端磁盘满 / 权限不足 /
  路径不存在 / 指纹变化），不是一句 "error"。

**界面**
- 深色 / 浅色，跟着标题栏那颗钮换；密度与字号在设置里调。
- 每个面板右键都有自己的菜单（会话栏、标签条、终端、文件块、传输抽屉、状态栏、标题栏），
  不会弹出浏览器那套菜单。
- 会话栏、文件面板、传输队列都能收起来；文件面板收起后右缘留一条细条，鼠标移上去点一下就能拉回来。

### 怎么装

1. 拿 `Portio_1.0.9-RC1_x64-setup.exe`（约 3.2 MiB），双击，按下一步装完。
2. 系统里需要有 **WebView2 Runtime**（Win11 自带；Win10 若缺，安装时会被引导去装）。
3. 装完桌面和开始菜单都有快捷方式。卸载走「设置 → 应用」，数据目录不会跟着删（见下）。

这是候选版（RC）：功能冻结，只修 Bug，不加新功能。包是发布构建（release，不是调试构建），
体积已按发布参数压缩。没有代码签名，Windows 的 SmartScreen 可能亮一次提示，选「仍要运行」。

### 第一次连一台机器

三种入口，挑顺手的：

1. **新建连接**——会话栏顶上那颗绿色按钮，填主机 / 端口 / 用户名，密码或私钥二选一。
2. **快速连接**——会话栏那行 `user@host:port`，写完回车。
3. **双击会话**——清单里双击已存的主机会直接重连；密码类会停在密码框等你输入。

第一次连一台新主机会弹指纹确认。核对一下那串 `SHA256:` 跟服务器上的一致（
`ssh-keygen -lf /etc/ssh/ssh_host_ed25519_key.pub`），对得上再点信任。

### 文件都放在哪

| 东西 | 路径 |
|---|---|
| 会话清单 | `%APPDATA%\io.portio.desktop\sessions.json` |
| 加密口令 | `%APPDATA%\io.portio.desktop\credentials.json` + `vault.key` |
| 已知主机指纹 | `%APPDATA%\io.portio.desktop\known_hosts` |
| 主题选择 | `%APPDATA%\io.portio.desktop\theme.txt` |
| 运行日志 | `%LOCALAPPDATA%\io.portio.desktop\logs\portio.log` |
| 程序本体 | `%LOCALAPPDATA%\Portio` |

想彻底清干净，卸载后把这两个目录一起删掉即可。

### 已知限制（这一版真的没有的东西）

- **只有 Windows**。macOS 与 Linux 还没开工，别指望今天能在 Mac 上装。
- **没有代码签名、没有自动更新**。升级靠手动换安装包；签名证书与更新端点都得先有人给我。
- **远端上报没做**。崩溃日志只写本机，不出网。
- **远端半截文件没有界面入口**：传输断了留下的 `xxx.portio-part` 要手动删。
- 分屏的格与格之间**不能拖动改宽窄**（等分）。
- 终端查找**只高亮当前一条**命中。
- 多行粘贴**只提示不拦截**（超过 2 行会提醒一次，仍然一次送下去）。

### 哪些是"代码写完了但没在真服务器上跑过"

我不想把没验过的说成验过。下面这些只有协议层单测与本地回环的证据，**未验证**：

- 真实登录会话、PTY 交互、`vim` / `tmux` / `htop` 全屏下的重绘与 resize；
- 真实 SFTP 上传下载，以及断网后断点续传能不能接上；
- 分屏里新开那条通道在真主机上的表现；
- 真实崩溃路径（panic 钩子只跑过落盘逻辑的单测）；
- 安装后的窗口在 WebView2 里的逐项点检（界面改动都是在无头 Chromium 里量的）。

我这边没有可用的测试服务器与凭据，所以这五项一直挂着。等有了机器就补。

### 隐私

会话与口令只在本机。口令是加密存的，但**主密钥和密文在同一台机器上**——这层防的是明文被人拷走，
不是防本机提权。软件不联网、不统计、不上报；唯一的网络连接是你自己要去的那台服务器。

### 反馈

出问题先看设置里的「运行日志」，点「复制诊断信息」，把那段贴给我——里面有版本、系统、
窗口尺寸和最近二十行日志，够定位八成了。

## 版本号怎么读

版本号 `v1.0.6-RC<n>` 拆开看：`1.0.6` 是「这一轮」的版本，`RC<n>` 是这轮里的第 n 个候选版（n 从 1 数）。
`Alpha` 阶段同理，每做完一件交付就进一位；满 10 进一位到 patch 再回到 `1`；进 RC 后功能冻结、只修 Bug，
进位规则不变；不带后缀就是正式版。规则写在 [`docs/versioning.md`](versioning.md)。
