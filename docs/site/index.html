一个窗口，两件事

SSH 终端和 SFTP 文件管理本来就该在一起：命令敲在中间，文件摆在右边， 不用在 ssh 和另一个客户端之间来回切。

01安装

拿到的文件形如 Portio_1.0.9-RC6_x64-setup.exe，双击、下一步、装完。

  1. 双击安装包。装的是当前用户，不弹管理员授权，位置在 %LOCALAPPDATA%\Portio。
  2. 桌面和开始菜单都会出现 Portio 快捷方式，图标是一个窗口：左边终端、右边文件。
  3. 第一次打开如果没反应：先确认机器上有 WebView2 Runtime（Win11 自带；Win10 缺的话安装包会引导你装）。
卸载：设置 → 应用 → Portio → 卸载。卸载只删程序，不动你的会话清单和已知主机； 真要清干净，再手动删 %APPDATA%\io.portio.desktop 与 %LOCALAPPDATA%\io.portio.desktop。

它现在还不做的三件事

  • 没有代码签名：Windows 可能先提示「未知发布者」，选「仍要运行」即可。
  • 没有自动更新：新版本自己下安装包装一遍，覆盖安装不会丢会话。
  • 崩溃只落本地：出问题写在本机日志里，不往任何服务器发（见下文「出问题先看这里」）。

02第一次连上

三条入口，挑顺手的：

  1. 新建连接：会话栏顶上那颗主按钮，填主机 / 端口 / 用户名，密码或私钥二选一。默认端口 22。
  2. 快速连接：会话栏那行 user@host:port，写完敲回车（或点右侧 ↵），连接面板会带着地址打开，只剩密码要填。这台机器以前连过的话，端口和认证方式按上次记录带出来。
  3. 双击会话：列表里双击。密钥认证的会直接连；密码的会停在密码框等你输入。
密码不保存。会话清单里只存「怎么连」：主机、端口、用户、认证方式、私钥路径。 这是我把密码当一次性东西用的默认做法——清单被谁看了一眼，也看不出你的口令。

想让它记住口令

连接面板里勾上「记住密码」，这一条凭据会用本机主密钥加密后写到 credentials.json （密钥在 vault.key，算法 AES-256-GCM，明文不落盘）。下次连这台机器不用再输。 要作废已存的口令：关掉程序，删掉 credentials.json 即可。

连上之后

  • 标签条每台机器一个标签，Ctrl+T 再开一个，Ctrl+W 关掉当前标签。
  • 终端右上角两个读数（列 × 行）跟窗口走，拖窗口大小时 PTY 也会跟着改。
  • 右边文件栏同时列远端和本地两块，双击目录进出，双击文件就传输。

03主机指纹

第一次连一台陌生机器，Portio 会把它的主机指纹记进 known_hosts； 之后再连同一台，指纹必须对得上。

指纹变了，我就直接停手，把新旧指纹都打出来，让你自己判断是不是重装过系统。 不会为了「让连接跑通」而放过去——这一条我从来没打算做成开关。

你想做的事在哪做
看记了哪些主机、各自指纹是什么设置 → 已知主机
某台机器重装过，要重新信任设置 → 已知主机 → 删掉那一条，下次连接会重新问一次
换机器时把信任关系带走复制 %APPDATA%\io.portio.desktop\known_hosts
删一条已知主机不是「以后自动信任」——它只是把状态退回从未连过，下次仍然要你确认。

04会话与分组

会话写在本机清单里（sessions.json），一次填好，下次双击就连。

  • 搜索：会话栏那行搜索框，按主机名、用户名或备注过滤，右边显示命中计数。
  • 分组：会话行右键 →「分到分组…」，填个组名（生产 / 测试 之类），列表就按组收拢。
  • 折叠：组标题点一下收起，只留标题和条数；组标题右键能「解散这个分组」。
  • 没分组的落在「未分组」；一条分组都没有时，列表仍按「最近使用 / 更早」排。
  • 重命名 / 删除 / 复制地址：都在会话行右键里。
会话栏、标签条、终端、文件栏、传输队列、状态栏、标题栏，每一块右键都有自己的菜单，跟那块的功能对得上；桌面上那套浏览器菜单不会冒出来。

05从别的工具搬过来

会话栏「导入会话」下拉里三项，读的是这些位置：

来源读哪里怎么处理
SSH 配置 %USERPROFILE%\.ssh\config 通配符块与 Match 块跳过并计数；IdentityFile 记为密钥认证
Xshell %APPDATA%\NetSarang\Xshell\Sessions 递归收子目录，一个 .xsh 一台主机；RDP / Serial 跳过
WinSCP %APPDATA%\WinSCP.ini → %LOCALAPPDATA%\WinSCP.ini → 文档\WinSCP.ini 取第一份存在的；FTP / WebDAV / S3 跳过，只收 SSH 系列站点

导入是合并：同一个「用户@主机:端口」只留一条，重复的不会覆盖你改过的备注名。 三个来源的密码字段一概不读——Xshell 与 WinSCP 的密码是各自加密的，读了也用不上。

导入完成后会告诉你收了多少条、跳过多少条。跳过的那几条通常是通配符块、非 SSH 的站点，或字段缺主机名。

06文件与传输

右边是两块列表：远端在上、本地在下，各自有路径栏、上级 ↑、刷新。

  • 双击目录进入；双击文件就传输（远端文件下载，本地文件上传到当前远端目录）。
  • 拖拽：把系统里的文件拖到本地栏，等于上传到当前远端目录。
  • 权限列：远端行最右边是 ls -l 形态的权限串（drwxr-xr-x），看不出来源时为 —。嫌窄可以关掉（设置 → 文件面板 · 权限列），关掉那 68 像素还给文件名。
  • 右键：远端行能下载 / 删除 / 重命名 / 新建目录；本地行能上传 / 重命名 / 在系统里打开。

传输队列

屏幕底部那条是队列，每条一个进度。研发电脑屏幕小的时候我把它做成能收起来的： 点标题条收起后只占一行，有新的传输会自动回到上次的高度。右键里也有「收起 / 展开传输队列」。

断了会接着传

  • 下载：先写成 文件名.portio-part，传完才改回原名。半途断了再点一次，只要半截文件还在、且比远端小，就从断点接着传。
  • 上传：远端先写 文件名.portio-part，整份传完再改名——所以远端永远看不到「传了一半叫正式名」的文件。
  • 不能续的情况：远端文件比本地半截还小（说明对面改了），会丢掉半截文件重来，而不是拼出一个坏文件。
远端残留的 .portio-part 目前没有界面清理：要删就去远端文件栏右键删除。这条已经记在待办里。

07终端与快捷键

终端是 xterm.js 渲染、russh 走协议，VT 序列、颜色、滚动缓冲都在。下面这些键位和软件里的「快捷键一览」是同一份内容。

窗口与标签

Ctrl+T新建连接
Ctrl+W关掉当前标签（只剩一个时不动，避免空窗口）
Ctrl+/打开快捷键一览（Esc 关闭）
Ctrl+Alt+H窗口全屏
Ctrl+Alt+B收起 / 展开左侧会话栏（也可以双击分隔把手）
Ctrl+Alt+F收起 / 展开右侧文件面板（折叠钮在终端标题条上，收起来后点右缘细条也能回来）
F5重绘终端与尺寸（不是重连）

分屏与查找

Ctrl+Shift+D左右分一格（同一主机再开一条通道）
Ctrl+Shift+E上下分一格
Ctrl+Shift+W关掉当前格（回到上一档格数）
Ctrl+F终端里查找（扫整条缓冲含滚动区，计数在右边；没命中数字转红，Esc 关闭）

格数只走 1 → 2 → 4；分到 3 格时第一格占满左列，不留空格子。当前格有一圈细描边，标题条上的列 × 行读数跟的是当前格。

复制粘贴

Ctrl+Shift+C / Ctrl+Insert复制选中
Ctrl+C有选中时复制；没选中就照发 ^C（中断当前命令，不打断你的手）
Ctrl+V / Ctrl+Shift+V / Shift+Insert粘贴

拖选只是高亮，不会自动进剪贴板——这是我从一开始就定下的习惯，想复制得自己按一下。 粘贴多行时会先提示一句「多行」，但不拦你。

08自定义

标题栏右上角三颗图标：主题、快捷键一览、设置。设置里十六项，分两批：改完立刻生效的， 和只管下一次打开时的。后者不会为了你改一个设置就把眼前的窗口重排一遍——它说的是下次。

改完立刻生效

设置项可选
主题深色 / 浅色 / 跟随系统（点标题栏那颗钮也能轮换）
强调色青（默认）/ 蓝 / 紫 / 琥珀 / 玫瑰 / 青柠。主色只管界面——按钮、选中、把手、终端光标； 终端里红绿黄蓝那套语义色不跟着变，grep 出来的绿还是绿。
界面字号标准 / 大一号。只抬界面文字（会话名、按钮、路径），终端里的字不动。
界面密度紧凑 / 标准 / 宽松，行高 24 / 28 / 32 像素，相邻两档差 4。只改高度，左右位置一寸不挪。
终端配色跟界面 / Dracula / Solarized / Nord。选了预设之后，界面切深浅都不再带动终端—— 终端那套色自己站住；光标始终跟主色走。
终端字号9–24，拖动即时生效；换字号会按新格子重算列数，读数跟着变。
等宽字体自动 / JetBrains / Cascadia / Consolas。机器上没装这一家就按次序回落， 绝不回落到比例字体——那会让每一列都错位。
文件面板 · 权限列显示 / 隐藏。藏起来那 68 像素还给文件名，行高和右对齐的两列一动不动。
终端滚动缓冲2000 行 / 8000 行 / 20000 行（新开的终端按这个来）

只管下一次打开

设置项可选
会话栏 · 启动时记住上次 / 总是展开 / 总是收起
文件面板 · 启动时记住上次 / 总是展开 / 总是收起
面板宽度 · 打开时记住上次 / 用默认。用默认 = 会话栏回到下面那档宽度、终端与文件各占一半、 传输队列回到一行高；分栏和抽屉不另给档。
默认会话栏宽度窄 200 / 标准 264 / 宽 328（像素）
终端 · 开局格数单屏 / 2×2 四格。只管打开时第一个标签摆几格，新开的标签仍是一格； 四格平摊，窄窗里每格会很窄。
「记住上次」与「用默认」是两层，不是二选一：拖出来的宽度永远记着，选「用默认」只是开机时不拿它当准。 哪天换回「记住上次」，上次拖到 360 它就还是 360——不会被默认值顶掉。

面板与维护

设置项可选
已知主机列出已信任的主机与指纹，可逐条删除；删一条只是让它下次重新走首次信任，不是关掉校验
运行日志日志路径、当前体积、「打开位置」「复制诊断」

这些都记在本机，下次打开还是你调的样子。界面元素的高度、间距、颜色都走同一套令牌， 深色浅色两套主题对得上——同一个钮在两个主题里不该长得不一样。这一页的每一项、 每一个档位都有一条脚本对着代码核（scripts/check_site.py），跟不上就会红。

09出问题先看这里

日志在哪

程序崩了、界面报错了，都会写进同一个文件： %LOCALAPPDATA%\io.portio.desktop\logs\portio.log。 一条一行，带 UTC 时间、级别、来源；单条过长会折行标记；文件满 1 MiB 轮转成 portio.log.1，只留一份。

设置 → 运行日志 里能看到路径和实时体积，两个按钮：打开位置（在资源管理器里定位到文件）、 复制诊断（版本号 + 系统 + 窗口尺寸 + 最近一段日志，可直接粘给我看）。

常见报错怎么读

报错会先说「发生了什么」，再说「下一步做什么」：

它说什么通常意味着你先做
认证被拒绝用户名、密码或私钥不对确认登录方式与凭据，私钥换了就把路径填对
连接被拒绝端口没开或被防火墙拦了确认服务端 sshd 在跑、端口对，别先怀疑客户端
连接超时网络不可达或服务端限流检查网络与白名单 / 安全组
权限不足账号对目标路径没权限换个目录，或换有权限的账号
远端磁盘已满目标分区写不进去了清理远端目录，或换目标路径
路径不存在目录被删或改名点刷新确认当前目录
主机指纹变化对面换了主机密钥先弄清是不是重装过；不是的话别连
匹配不上规则时，报错会原样保留服务端原文——宁可粗糙，也不替你猜。 原文贴进搜索框，通常比我给的概括更准。

界面不对劲

  • 窗口拉窄到 1024×620 时各面板仍然不越界、不裁切、不叠字。
  • 哪个面板右键没菜单、或冒出了浏览器那套菜单，都算缺陷，请记下来告诉我。
  • 文件面板折叠后，右缘平时什么都不画，鼠标移上去才淡出一条 ‹——这是刻意的，不是漏画。

10文件都放在哪

路径里面是什么
%APPDATA%\io.portio.desktop\sessions.json会话清单（怎么连，不含密码）
%APPDATA%\io.portio.desktop\credentials.json勾了「记住密码」的那些口令，加密存放
%APPDATA%\io.portio.desktop\vault.key加密用的本机主密钥；和凭据一起拷走才能解密
%APPDATA%\io.portio.desktop\known_hosts已信任的主机指纹
%APPDATA%\io.portio.desktop\theme.txt上次选的主题
%LOCALAPPDATA%\io.portio.desktop\logs\portio.log运行日志（轮转文件为 portio.log.1）
%LOCALAPPDATA%\Portio程序本体

换电脑：拷 %APPDATA%\io.portio.desktop 整个目录过去，会话与已知主机就跟着走了。 带走 vault.key 等于带走保存的口令，自己判断要不要一起拷。

11版本与进度

版本号形如 v1.0.9-RC6：每完成一个交付单元进一位，满 10 进 patch 再回到 1。 进 RC 后功能冻结、只修 Bug，进位规则不变。标题栏上显示的就是当前版本。

版本范围
v0.1 能连能敲外壳、SSH、终端、会话树
v0.2 会话管理与迁移会话 CRUD、分组、导入 Xshell / WinSCP / ssh config、快速连接、设置项
v0.3 文件双栏SFTP 双栏、传输队列、断点续传
v0.4 打磨发布主题全量、签名、自动更新、文档站

逐版做了什么写在仓库根的 CHANGELOG.md；设计约束写在 docs/design-spec.md； 这一轮还没做的事记在 docs/backlog.md。
