# 设计令牌

唯一来源是 `ui/tokens.css`。组件里不许出现裸色值，要新色就回这里加变量。

## 色彩（深色）

| 令牌 | 值 | 用途 |
|---|---|---|
| `--bg` | `#0D1014` | 窗口底 |
| `--surface` | `#131820` | 标题栏、会话栏 |
| `--surface-2` | `#1A2029` | 抽屉、面板 |
| `--surface-3` | `#222A35` | 悬浮、选中底 |
| `--line` | `#262E3A` | 发丝分隔线 |
| `--text` / `--text-2` / `--text-3` | `#DFE5EC` / `#8B96A5` / `#5E6875` | 正文 / 次要 / 元信息 |
| `--accent` | `#2FB39A` | 连接态、进度、焦点环 |
| `--info` | `#6FA8DC` | 可点对象（目录、链接） |
| `--warn` / `--danger` | `#C99A4E` / `#D2655F` | 异常与失败 |
| `--term-bg` | `#090C10` | 终端背景，比窗口底更深 |

浅色主题只换值不换名，组件不改代码。

## 尺度

- 圆角 4 / 8 / 12；表格行不做圆角
- 字号 11 / 12 / 13 / 14 / 16 / 20
- 行高：紧凑 24 / 标准 28
- 结构尺寸：标题栏 38、状态栏 26、会话栏 264、传输抽屉 172
- 动效 160ms，只用于抽屉、主题、tab；终端内不做动效

## 字体

等宽 `JetBrains Mono` / `Cascadia Mono`（数字列必须 tabular-nums），界面 `HarmonyOS Sans SC` / `PingFang SC`，都走系统栈，不加载 Web 字体。
