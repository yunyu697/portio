## UI / 体验

- **快捷方式图标改用按版本命名的 ico 路径**（如 `%LOCALAPPDATA%\Portio\icons\portio-<version>.ico`）。Windows 按"路径 + 时间"缓存图标，换新路径就不会命中旧缓存，安装后无需重启资源管理器也能立刻看到新图标——比"装完刷图标缓存"体面得多。
- **终端画布是否随设计语言收圆**：现在终端区是满幅直角，窗口本身是圆角，收 8px 可能更统一，但要先确认不裁掉 xterm 边缘字符。
- **传输抽屉的进度条材质**：现在是细线＋百分比，可换成更细腻的包边胶囊，和整体"少而准"的材质语言一致。
- **会话行拖拽分组**：S5 剩余项，需要 HTML5 drag 或 pointer 拖排，落盘顺序。

## 工程 / 发布

- **CI**：仓库无远端，先不接；等 GitHub 流程定了再补 build + test 工作流。
- **macOS / Linux 打包**：S13/S14 范围，`icon.icns` 还是旧文件，需按 iOS/macOS 圆角规范重出。
- **签名**：Windows 代码签名证书未定，未签名安装包会触发 SmartScreen 提示。
- 远端 `.portio-part` 半截文件目前在目录列表里和普通文件一样（v1.0.3-Alpha10 起上传续传也会留这种文件）：要不要给它「未完成」标记、要不要提供一键清理入口，等用户拍板。
- 主机密钥变更的「一键信任」入口：现在路径是拦下 → 去设置删记录 → 重连重新 TOFU。行为是对的（不给默认放行），但多一步。要不要做「我确认这是新机器」的显式确认按钮，需要拍板——涉及安全默认值，不自作主张。
