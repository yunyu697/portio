# Portio 界面设计规范 v2（全覆盖）

> 这份文档是 UI 的**唯一裁判**。改界面之前先对照它；改完用第 13 节的清单自查。
> 规范与排期冲突时，先改规范再改代码——不要"先做出来再说"。
>
> **v2 的改动**：v1 是"发现一条补一条"，分界线粗细、标题条高度、缩放错位都属于规范没覆盖到的空白。
> v2 改成**先列清单再定条款**：界面上的每个元素都必须能在 §10 覆盖矩阵里找到自己那一行，
> 每个方面（尺寸 / 间距 / 对齐 / 层级 / 状态 / 动效 / 文案）都必须有条款。
> **元素不在矩阵里 = 规范有缺口 = 先把矩阵补上，再写代码。**

## 0. 适用范围

覆盖四类界面：主窗口骨架（标题栏 / 会话栏 / 终端 / 文件 / 传输抽屉 / 状态栏）、
浮层（模态、右键菜单、toast）、控件（按钮、输入、分段、滑块、列表行），
以及与它们相关的所有方面（几何、色彩、字体、图标、状态、动效、文案、空态）。

不覆盖：系统窗口边框与 DPI 缩放（由 Tauri / Windows 处理）、终端内部字符渲染（xterm.js）。

## 1. 三条底层原则

1. **一个记忆点**：整套界面只有"青绿强调色 + 细结构线"这一组特征反复出现，其余全部安静。
2. **结构线即信息**：每条线都要回答"这是两个区域"还是"同一组里的两行"。没有信息作用的线不画，有信息作用的线必须画得出来。
3. **同层级同长相**：同一层级的元素，圆角、描边、间距、字号、高度必须来自同一档取值。跨层级才允许不同。

**刻度纪律**（`scripts/check_ui_scale.py` 扫 `ui/index.html` 与 `ui/app.js` 强制）：
- `gap / padding / margin` 只许 `0 / 1 / 2 / 4 / 8 / 12 / 16 / 24`；
- `height` 只许 `--row / --ctl / --ctl-2 / --ctl-3` 或发丝档（1 / 2 / 3 / 6 / 8 / 9 / 16 / 18）；
- `font-size` 只许令牌；`border-radius` 只许令牌或 `50%`（圆点）。

## 4. 对齐规则

- **同一行里的东西一律垂直居中**（`align-items:center`），不许用 padding 硬凑基线。
- **左右内边距**：面板级 12、行内控件 8、行内文字 12。同一层的左缘必须重合——标题条文字、列表行首文字、输入框左缘在同一条竖线上。
- **右侧动作区**：`margin-left:auto` 贴右，间距 4；图标按钮等宽（34 或 `--ctl`）。
- **图标盒**：16 / 18 的盒居中于行，不按字形自身高度对齐；SVG 统一 `display:block`。
- **列表单行**：`overflow:hidden` + `text-overflow:ellipsis` + `white-space:nowrap`；标题优先截断，右侧元信息（端口、认证、大小）不截断。
- **数字右对齐**：文件大小、条数、时钟、计数器用 `--mono` 并贴右。
- **分组层级**：组标题与组内行左缘相同，用 caret 表达层级，不靠缩进。

## 5. 分隔与边界

三种线，职责唯一，不互相顶替：

1. `--line-strong`（1px）：区域之间——标题栏下沿、会话栏右界、终端/文件之间、终端/抽屉之间、状态栏上沿、文件栏远端/本地之间。静止必须看得见，**且同一处只有一条线**（不许某块自己再画 border 叠成 2px）。
2. `--line`（1px）：同一区域内的行——会话行、文件行、标签页之间、抽屉内。
3. `--line-soft`：hover / 选中底色，不承担分界职责。

把手：
- 位置**由布局算**：纵向把手占所在断点的 0 宽栅格轨并 `margin-left:-4px` 溢出；横向把手 `top: calc(100% - var(--drawer))`。禁止 JS 量像素贴边（窗口缩放与 `minmax` 夹取时会错位）。
- 静止：只留 1px `--line-strong`，不留高亮。
- hover：结构线隐去，换 2px 渐变高亮（`--accent`，22% / 78% 处淡出到透明），不透明度 75%；横向把手方向 90°。
- 拖拽：3px、100%、`0 0 10px` 外发光；拖拽期间关掉栅格过渡。
- 会话栏折叠：收成 10px 贴边条，`inset -1px` 画线，hover 才亮箭头，不画渐变。

## 6. 图标

- 一律内联 SVG 线性图标，16 / 18 两档，描边 1.5px，`currentColor`，**不许位图、不许自带底板**。
- 深浅主题只换颜色，不换形状、尺寸、基线。
- 标题栏按钮图标盒统一 18×18；状态型图标（主题切换）必须反映当前实际状态。

## 7. 字体与字号

- 界面字族 `--ui`，终端与数值 `--mono`。
- 字号只取四档：标题 13、正文 12、辅助 11、大标题 14。不许出现第五档。
- 行高：中文 1.5、等宽 1.35；不写字号与行高的裸组合。

## 8. 动效

- 时长 `--dur`（160ms，颜色/透明度）、`--dur-2`（240ms，位移/尺寸）；曲线 `--ease` / `--ease-out`，不自造第三条。
- 只给因果明确的动作加动画：展开、收起、弹层进出、拖拽起止、标签切换。列表滚动、窗口缩放不加。
- 拖拽期间禁止过渡；`prefers-reduced-motion` 下全部压到 0。

## 9. 状态矩阵（任何可交互元素都必须定义这七种）

| 状态 | 视觉 | 适用 |
| --- | --- | --- |
| 默认 | 底 `--surface-2/3`，文字 `--text-2` | 全部 |
| hover | 底提亮一档或加 `--line-soft`，文字 `--text` | 按钮、行、标签、图标按钮、把手的渐变 |
| active / 选中 | 底 `--surface-3`，左/下 2px `--accent` 或文字 `--accent` | 标签、会话行、分段控件当前项 |
| focus | 1px `--accent` 内描边（不画系统虚线框），键盘 Tab 可达 | 输入、按钮、列表行 |
| disabled | 文字 `--text-3`，不响应，不画阴影 | 按钮、输入 |
| 拖拽中 | 见 §5 把手，光标 `col-resize` / `row-resize` | 把手、文件拖入 |
| 加载 / 进行中 | 文案省略号或进度条（`--r-hair` + `--accent`），不画转圈插画 | 目录读取、传输 |

## 11. 文案

- 一种语气：**说能做什么，不说系统状态**（"连上主机后显示远端目录"，而不是"远端目录为空"）。
- 报错给人话 + 下一步（"主机指纹变了：旧 xx / 新 xx，先确认不是被劫持再连"），不抛栈、不抛错误码。
- 按钮用动词短语（"新建连接""导入 Xshell 会话"），"取消 / 完成"除外。
- 空态最多三行，第二行给操作提示（含键位）。

## 13. 每轮 UI 改动的验收清单

1. `python scripts/check_design_tokens.py` → `OK`（无硬编码色值）。
2. `python scripts/check_ui_scale.py` → `OK`（字号/圆角/间距/高度全在刻度内）。
3. `node --check ui/app.js` 通过；无头 `--dump-dom` 标题不含 `ERR:`。
4. 浅色、深色各一张；1440×900 与 1180×690 各看一次；窄窗口（1024×620）再确认不重叠不裁切。
5. 结构线自检：五条结构线都在，相邻两条粗细一致。
6. 标题条自检：会话 / 终端 / 文件 / 传输队列四条同高。
7. 圆角自检：面板内嵌控件圆角小于外框；同级不出现直角与圆角并存。
8. 图标自检：深浅各看一遍，无位图、无底板、基线齐平、16 与 18 两档不混用。
9. 状态自检：随手挑三个可交互元素，确认默认 / hover / 选中 / 禁用有差别且来自 §9。
10. 动效自检：`prefers-reduced-motion` 打开一次，确认没有残留长动画。
11. 涉及真实窗口的改动，实机启动截屏一次，并在提交正文写明"未验证"项。

## 14. 变更流程

- **新增元素**：先在 §10 加一行（层级 + 条款），再写代码；没进矩阵的元素不接受。
- **新增令牌**：先在 §2 / §3 加条款，再写 `tokens.css`；深浅两套同时给。
- **一次性试验**：写进 `docs/backlog.md`，不进主干样式。
- 规范版本随 CHANGELOG 的 `Changed` 小节更新；本文件末尾记修订。
