# Portio 界面设计规范 v1

> 这份文档是 UI 的**唯一裁判**。改界面之前先对照它；改完用第 11 节的验收清单自查。
> 规范与排期冲突时，先改规范再改代码——不要"先做出来再说"。

## 0. 为什么要有它

前几轮反复返工的都是同一类问题：分隔线看不见、图标带深色底板、圆角只在外框上有、动效忽快忽慢。
根因不是单点做错，而是**没有一套写下来的判定标准**，每次都在凭当下感觉改。
所以这份文档只做一件事：把"精致"翻译成可检查的条款。

## 1. 三条底层原则

1. **一个记忆点**：整套界面只有"青绿强调色 + 细结构线"这一组特征反复出现，其余全部安静。
2. **结构线即信息**：每一条线都在回答"这是两个区域"或"这是同一组里的两行"。**没有信息作用的线不画**，有信息作用的线必须画得出来。
3. **同层级同长相**：同一层级的元素，圆角、描边、间距、字号必须来自同一档取值。跨层级才允许不同。

## 2. 色彩

所有颜色只能来自 `ui/tokens.css` 的主题令牌，**界面文件和 app.js 里不允许出现硬编码色值**（`scripts/check_design_tokens.py` 会拦）。

| `--surface` | `#131820` | `#ffffff` | 主面板底 |
| `--surface-2` | `#1a2029` | `#f7f9fa` | 次级面板（文件栏、抽屉） |

- 强调色一屏最多三处（主按钮、当前标签、拖拽中的把手）。第四处就算滥用。
- 深浅两套必须**同结构同名**：新增一个令牌就要同时给出两套值，缺一套视为未完成。

## 3. 圆角阶梯

| 令牌 | 值 | 用在哪 |
| --- | --- | --- |
| `--r-4` | 4px | 行内小控件、标签、徽标 |
| `--r-6` | 6px | 输入框、按钮、列表行 |
| `--r-8` | 8px | 面板、抽屉、弹层卡片 |
| `--r-12` | 12px | 模态层、需要强调的浮层 |
| 窗口 | 10px | 无边框窗口自身（由系统裁剪，代码里不另画） |

硬性条款：
- 同一层级**不允许直角与圆角并存**。面板是 8，面板里的输入就必须是 6，不能一个 8 一个 0。
- 内嵌元素的圆角要小于外框（外 8 内 6 外 8 内 4 都可，反过来不行）。
- 满幅铺开的画布类区域（终端画布、文件列表滚动区）按第 9 节处理，不得自成一套。

## 4. 分隔与边界

三种线，各有唯一职责，不互相顶替：

1. `--line-strong`（1px）：**区域与区域**的分界——标题栏下沿、会话栏右界、终端与文件栏之间、终端与传输抽屉之间、状态栏上沿。静止状态必须看得见。
2. `--line`（1px）：**同一区域内的行**——会话行、文件行、标签页之间。
3. `--line-soft`：hover / 选中底色，不承担分界职责。

把手（gutter）规则：
- 静止：只留 1px `--line-strong` 结构线，**不留高亮色带**。
- hover：结构线隐去，换成 2px 的**渐变高亮**——`linear-gradient` 在中段实、靠两端（约 22% / 78% 处）淡出到透明，颜色 `--accent`，整体不透明度 75%。横向把手按 90° 方向做同样的渐变。
- 拖拽：高亮加粗到 3px、不透明度 100%，并带一圈 10px 的 `--accent` 外发光；拖拽期间关掉面板的栅格过渡，保证跟手。
- 这条高亮只在"能拖的地方"出现，所以它必须比结构线更抢眼；但静止时一根都不能残留。
- 会话栏折叠后：把手收成 10px 宽的贴边条，`inset -1px` 画线，hover 才亮箭头，此时不画渐变高亮。

## 5. 图标

- 一律**内联 SVG 线性图标**，尺寸 16 / 18 两档，描边 1.5px，颜色走 `currentColor`，**不允许位图、不允许自带底板**。
- 深浅主题下同一枚图标只换颜色，不换形状、不换尺寸、不换基线对齐。
- 标题栏按钮的图标盒统一 18×18，垂直居中对齐；不允许某个图标因为字形原因偏上或偏下。
- 状态型图标（主题切换）必须反映**当前实际状态**：深色显示月亮、浅色显示太阳，点击后立即换成相反那枚。

## 6. 字体与字号

- 界面文字用 `--ui`（系统 UI 字族），终端用 `--mono`。
- 字号只取 `--fs-11 / --fs-12 / --fs-13 / --fs-14` 四档。标题 13、正文 12、辅助 11。
- 中文行高 1.5，等宽字体行高 1.35；行长按屏宽自适应，不做硬断行。

## 7. 间距与密度

- 间距只用 4 的倍数：4 / 8 / 12 / 16 / 24。
- 面板内边距 12，面板之间不留白（靠结构线分界）。
- 行高：标准 `--row: 28px`，紧凑 `--row: 24px`，由 `data-density` 统一切换，不允许局部写死。

## 8. 动效

- 时长三档：`--dur` 120ms（颜色、透明度）、`--dur-2` 240ms（位移、尺寸）、`--ease` / `--ease-out` 两条曲线，别自造第四条。
- 只给**因果明确**的动作加动画：展开、收起、弹层进出、拖拽起止。列表滚动、窗口缩放不加。
- 拖拽过程中禁止过渡（会拖手）；`prefers-reduced-motion` 下全部压到 0。

## 9. 组件级条款

| 组件 | 条款 |
| --- | --- |
| 标题栏 | 高 `--titlebar`，底部 1px `--line-strong`；左侧品牌标记 + 名称 + 版本；右侧图标按钮组右对齐，间距 4 |
| 会话栏 | 宽 `--sidebar`，右侧 1px `--line-strong`；行 hover 用 `--line-soft`；折叠后整块移除，只留把手 |
| 终端标签条 | 高 `--row`；激活标签底部 2px `--accent` 短线；关闭按钮 hover 才显形 |
| 终端画布 | 满幅，背景 `--term-bg`；与上方标签条之间 1px `--line` |
| 文件栏 | 背景 `--surface-2`；远程/本地两段之间 1px `--line-strong`；列头与行同高 |
| 传输抽屉 | 顶部圆角 `--r-8`，上沿 1px `--line-strong`；空态一行提示，不画插画 |
| 弹层 / 右键菜单 | 圆角 `--r-8`（菜单）/ `--r-12`（模态）；1px `--line`；阴影克制，只一层 |
| 滚动条 | 细：8px 轨道内 6px 拇指，圆角 999，`--line-strong`→hover 加深；不做系统粗条 |
| 状态栏 | 高 `--statusbar`，上沿 1px `--line-strong`；左连接状态、右时钟，字号 11 |
| 面板标题条 | 会话 / 终端 / 文件 / 传输队列**四条一律高 `--row`**（标准 28 / 紧凑 24），字号 11、左右内边距 12、下沿 1px；不允许某一条单独取 30 或写死 28px |
| 把手定位 | 纵向把手占所在栅格断点的 0 宽轨、自身溢出 4px；横向把手 `top: calc(100% - var(--drawer))`。**位置由布局算，不用 JS 量像素**——量像素会在窗口缩放、栅格夹取时错位 |

## 11. 每轮 UI 改动的验收清单

改前对着规范定方案，改完逐条自查并在提交正文里写证据：

1. `python scripts/check_design_tokens.py` 通过（界面文件无硬编码色值）。
2. `node --check ui/app.js` 通过；无头 `--dump-dom` 标题不含 `ERR:`。
3. 浅色、深色各截一张；1440×900 与 1180×690 各看一次，无重叠、无裁切。
4. 结构线自检：截图里能数出标题栏下沿、会话栏右界、终端/文件分界、抽屉上沿、状态栏上沿这五条线。
5. 圆角自检：抽查任一面板，其内嵌控件圆角小于外框。
6. 图标自检：深浅各看一遍标题栏与标签条，无位图、无底板、基线齐平。
7. 动效自检：`prefers-reduced-motion` 打开一次，确认没有残留长动画。
8. 涉及真实窗口的改动，实机启动截屏一次并写明"未验证"项。

## 12. 变更流程

- 新增令牌 / 新组件：先在本文件加条款，再写代码。
- 一次性试验允许，但必须写进 `docs/backlog.md` 而不是直接进主干样式。
- 规范版本随 CHANGELOG 的 `Changed` 小节一起更新；本文件末尾记录修订。
